Student Report Delivery

Upload the teacher's CSV or Excel file. The app will generate bilingual (English+Urdu) PDFs for each student and attempt to send email/WhatsApp when configured.

Sample file

You can test with sample_students.csv.

Notes

  • If SendGrid/Twilio not configured, the app will still generate PDFs and a ZIP for manual distribution.
  • Make sure to install wkhtmltopdf and set WKHTMLTOPDF_PATH environment variable if needed.
